# ファイル弾幕 設計メモ

`EP_MODs/file-danmaku/mod/`（`neo.file-danmaku`、`location: "folder"`）。ファイルを弾にして、3D の弾幕ボスに撃ちこむゲーム。**大きいファイルほどロマン砲**。
ファイルには一切さわらない。読むのは、フォルダの中の名前・種類・大きさだけ。書き換え・移動・削除・ごみ箱・ファイルの中身の読み取りは、一度も呼ばない（`unit.mjs` が、呼んでいないことを調べる）。

## 2.0 の変更点（ユーザーの声 2026-10-24）
1. 出撃前の画面に、弾の種類ごとの **特性の説明（絵つき）**。
2. マガジンは 8 つ固定をやめて、**2 次元の容量マップ（パズル）**。重いファイルは大きな形で、少ししか持てない。軽いファイルは小さな形で、たくさん持てる。形は ファイルごとに決まっていて、回して、すきまに はめこむ。
3. 遊ぶと **強化素材** が手に入る。**マガジンの広さ・新しい役の解放・攻撃力・ライフ・速さ** などを伸ばせる。そのぶん、面が進むほど 敵も強くなる。
4. 敵も 上下左右前後に動く。場を 広く 立体的に使う。
5. **一人称視点**。マウスで見る向きを変える。キー操作は **片手（左手）で全部できる** ようにして、**キーの割り当てを自分で変えられる**。

## 2.1 の変更点（ユーザーの声 2026-10-24）
1. **上や下からの攻撃に気づけない** → 画面に入っていない所から 衝突コースで来る弾を、画面のふちの しるしと「▲ 上から」「▼ 下から」で知らせる。レーダーに 高さの目盛りを足す（下の「危険の合図」）。
2. **探しかた・並べかたが 大きさだけ** → 名前・弾の種類・大きさの段で しぼりこめる。並べかたは 6 種類（更新日つき）。「下の階層もさがす」も、同じ条件で探す。小さいファイルも探せる。
3. **一覧が見つけにくい** → 一覧をやめて **グリッド**。1 つのマスには **形・弾の種類・威力** だけ。名前と大きさ・更新日は、触れたときの詳細に出す。

## 2.2 の変更点（ユーザーの声 2026-10-24）
1. **フォルダが そのままボスになる**。「挑めるフォルダをさがす」で、いまの到達で 挑めるフォルダだけが 一覧に出る。選ぶと、中身（大きさ・ファイルの数・拡張子の割合）から、そのフォルダだけのボスができる。上へ たどっていくと ドライブが **ラスボス**（到達が 8 になるまでは 封印）。
2. 大きさに天井がある（TB のドライブでも ふつうに戦える）。一方で、小さい物が 強すぎることも ない。**サイズ感のつりあい**は、下の「フォルダのボス」の表で決める。
3. **進行度の初期化コマンド**（デバッグ用）。コマンドの一覧（Ctrl+Shift+P）に「進行度を初期化」。

## フォルダのボス（`folderboss.js`）
**考え方**：ファイルを「弾」にするだけでなく、場所（フォルダ）も「敵」にする。エクスプローラで 歩きまわること自体が、ステージ選びになる。盤は フォルダをまたいで持ち歩けるので、**ほかのフォルダで拾った弾を持っていって 戦う**。

**挑めるフォルダを さがす**（いま開いているフォルダから下）：フォルダのボスの見出しの「挑めるフォルダをさがす」を押したときだけ、はじまる。**いまの到達で 挑めるフォルダ**だけを集めて、一覧にする。ユーザーが そこから 選ぶ。
- **なぜ「いまのフォルダを調べる」をやめたか**：開いているフォルダが はるか格上だと、格上しか見つからず、挑めない。先に「挑めるもの」を探して 並べるほうが、エクスプローラで 歩く楽しさに合う。
- 探しかた（浅いほうから）：
  1. いまのフォルダを 本体の `search.stats` で数える（大きさ・ファイルの数・拡張子ごと）。**ドライブの根は 数えない**（格 8 とわかっているので、すぐ 子へ）。
  2. 挑める（本来の格 ≦ 到達）なら **候補**。そこから下は 掘らない（中のフォルダは、その候補の一部なので）。
  3. 格上なら、**子のフォルダ**（`search.find` の `kind: "folder"`、`depth: 1`）を 1 つずつ 同じように数える。深さは 3 まで。
  4. 数えるのは 40 か所まで、時間は 90 秒まで、候補が 24 たまったら そこまで。ボタンを もう一度押すか「やめる」で 途中でやめられる。やめても、そこまでの候補は 残る。
  5. ファイルが 3 つ未満のフォルダは ボスにならない。
- **いまの到達にまだ早い**フォルダも、近いもの（本来の格が 到達 + 2 まで。ドライブの根は ラスボスとして）を 最大 6 つ 別枠で見せる。「あと N 面クリアで 解禁」と出し、押すと 中身の予告は 見られるが、挑めない。
- 一覧：格が高い順（ちょうどいい手ごたえのものが 先）、同じなら 大きい順。制覇した所に ✓。1 つ選ぶと、右に ボスの詳細（中身の割合・フェーズ・苦手と得意・素材の見込み）と「このフォルダに挑む」。
- 結果は 開いているあいだ 覚える。到達が進んだら、数えなおさずに 一覧を 作りなおす（掘らなかった所は 掘れていないので、必要ならもう一度さがす）。
- 本体の `folderSize`（フォルダを開くたびに すべての子の大きさを 勝手に数える）は 使わない。重いので、「押したときだけ」を守る。

**格**（強さの目盛り。1〜8。面の番号と同じ強さ）：サイズの 4 倍ごとに 1 つ上がる。
| 合計の大きさ | 格 |
|---|---|
| 80MB 未満 | 1 |
| 〜320MB | 2 |
| 〜1.25GB | 3 |
| 〜5GB | 4 |
| 〜20GB | 5 |
| 〜80GB | 6 |
| 〜320GB | 7 |
| それ以上 | 8 |
- 数えきれずに「途中まで」になったときは、すくなくとも 7。**ドライブの根（C:\ など）は いつも 8**。ラスボス。
- 格 8 でも、面の 8 と同じ強さで、それ以上にはならない（天井）。TB のドライブも、TB を 100 倍した フォルダも 同じ強さ。そのかわり、大きいフォルダほど フェーズが多く（格 5 から 4 つ）長い。
- **挑める条件**：本来の格 ≦ いまの到達（クリアした面 + 1）。格を おさえて 戦わせることは しない（格 3 と書いてあれば、面の 3 と 同じ強さ）。はじめは 80MB 未満の フォルダだけ。クリアするほど、大きなフォルダに 挑める。ドライブの根（格 8）は、到達が 8 になるまで 挑めない。

**中身 → ボス**
- 拡張子を 弾の種類にまとめ、**大きさ（バイト）の割合**で 数える。いちばん多い種類が **本性**。ボスの色・形・名前の肩書きが決まる。
- **フェーズ**：割合の多い種類から 順に、その種類の「好み」の弾幕になる（足りなければ くりかえす）。最後のフェーズだけ 1 本多い。
| 種類 | ボスの肩書き | 好みの弾幕 |
|---|---|---|
| 砲弾（そのほか） | 巨人 | 輪・扇 |
| 散弾（画像） | 写真の群れ | 小雨・花・輪 |
| 光線（動画） | 映写機 | レーザー・壁 |
| 音波（音楽） | 楽団 | 輪・蛇・渦巻き |
| 誘導弾（文書） | 書類の山 | 扇・追う玉・雨 |
| 集束弾（圧縮） | 梱包 | 咲く玉・全方向 |
| 爆裂弾（実行ファイル） | 常駐 | 全方向・柱・雨 |
| 隕石（イメージ・データ） | 巨塊 | 柱・雨・壁 |
- 体力・時間・弾の数と速さは、**格**の面と同じ式（`stages.js`）。
- **得意と苦手**：本性の種類の砲は 効きにくい（ダメージ ×0.8）。そのフォルダに ほとんど無い種類（割合 3% 未満から 1 つ。種から決まる）の砲は 効きやすい（×1.4）。ふつうの弾は 変わらない。画面の上の体力のそばに 出す。**苦手な砲を 盤に入れて持っていく**のが 作戦になる。
- **同じフォルダは いつも同じボス**（名前から決まる種。中身が変われば ボスも変わる）。

**制覇と素材**
- 倒したフォルダの場所を 覚える（`ep.storage` の `rec.conquest`）。ファイルの一覧で、制覇した フォルダの札に ✓ がつく。
- 素材は 面のクリアと同じ式（格）。**同じフォルダを 同じ格か それ以下で 倒しなおすと、素材は 35%**（足し算の かせぎ対策）。格が上がってからの再挑戦は 満額。
- クリアすると 到達も進む（格 N を倒すと、到達は N + 1 以上）。ふつうの面と 同じ通し番号で つながっている。
- やられても、倒したフェーズのぶんだけ 素材。

**まだやらないこと**（次の候補）：中のファイルの アイコン・サムネイルを 弾の絵にする（`icons` `thumbnails` が要る。「中身は読まない」の説明の書きかえも要る）、フォルダの変化（`onChanges`）で 乱入、更新日の古さを レアリティにする、日替わりのボス。

## 進行度の初期化（デバッグ用）
- コマンドの一覧に「進行度を初期化」（ヒント：デバッグ用）。押すと、本体の確かめの画面で 確認する。
- 消えるもの：ベスト・到達した面・最大の一撃・制覇したフォルダ・強化素材・強化・解放した役（`rec` と `meta`）。
- 残るもの：キーの割り当て・視点の設定（`bind` `look`）・並べかたの選び・盤に置いた弾。ファイルには 一切さわらない。
- 戦いの最中なら その戦いを やめて、武器庫にもどる。

## 使う情報（manifest の uses）
`entries`（今のフォルダの中身）・`size`（ファイルの大きさ）・`modified`（更新日。並べかたの「新しい順」に使う）・`search`（「大物をさがす」を押したときだけ、下の階層を検索）・`pointerLock`（一人称で、マウスの動いた量を受け取るため。マウスを固定するだけで、ほかには何もしない）。通信はしない。

## 遊びの流れ
1. **武器庫**（出撃前の画面）：左に 4 つの見出し
   - **ファイル**：今開いているフォルダのファイルが、**グリッド**に並ぶ。1 マスに出るのは、ファイルの **形・弾の種類（記号と名前）・威力** だけ（大きさの段は 下の線の色）。名前・大きさ・更新日は、マスに触れたときの 詳細（左の下）と、マスの吹き出しに出る。フォルダは 上の小さな札で、押すとそこへ入る。
     - **しぼりこみ**：名前の文字（`*` `?` が使える。空白で区切ると すべてを含む）・**弾の種類**（8 種類。いくつでも）・**大きさの段**（豆鉄砲〜超ロマン砲。いくつでも）。何も選ばなければ ぜんぶ。
     - **並べかた**：大きい順・小さい順・名前順・種類順・新しい順・古い順。選びは 覚えておく。
     - **下の階層もさがす**：いまのしぼりこみの条件で、そのフォルダ以下を探す（名前・拡張子・大きさを 本体の検索に渡す。1 回 5000 件まで）。条件が何もないときだけ、20MB 以上に する。結果にも、同じしぼりこみと並べかたが効く。「もどる」で このフォルダへ。
     - 「おまかせ詰め」は、**いま見えているファイルだけ**から詰める（たとえば 動画だけ・小さいものだけ で詰められる）。
   - **弾の図鑑**：8 種類の弾の 絵と、撃ち方・特性。
   - **役の一覧**：全部の役。条件・効果・解放しているか。
   - **整備場**：強化素材と、強化。
   右は **マガジン**（容量マップ）。ファイルの形を、盤にはめる。盤の下に、成立している役の名前（触ると 効果が出る）と、能力の合計。左の下には、さわっているファイルの 形・威力・溜め・マス数。上の右には 持っている素材。
2. **出撃**：面を選び（クリアした面まで）、難しさを選ぶ。出撃した直後に、成立した役と効果を数秒出す。戦いの最中は、役の名前を左上に出しつづける。
3. **戦い**：ボスは 3〜4 のフェーズ。フェーズごとに 体力・制限時間・弾幕・動き方・弱点の入れかわる間隔が決まっている。体力を削りきると次のフェーズへ。時間切れでも次へ進む（ボーナスなし）。最後のフェーズは時間切れがなく、のこり時間が尽きると弾が増えて速くなる。
4. **面クリア**：素材が手に入る。のこった弾は 盤に置いたまま持ち越し、空いた所に 足せる。減ったライフは 1 回復する。やられると、素材は その面で倒したフェーズのぶんだけ手に入り、出撃したときの装填で「もういちど」。

## 世界
- 場は 半径 30 の円柱で、床は 0、天井は 24。勇者は 高さ 1〜21 を 自由に飛ぶ（上下左右前後。水平 9.5、上下 6.5 の速さ）。ボスは 中心から半径 16、高さ 6〜17 の中を 動きまわる。
- あたり判定は、勇者が半径 0.2 の **3D の球**。弾はそれぞれの半径。ボスの体は 半径 3（ぶつからないよう、近づけるのは 6 まで）。かすり（弾の半径 + 0.85 以内）で、スコア +100、溜め +0.05 秒。
- 描画は WebGL2。光る板（sprite）と太さのある線（line）だけ。`render.js` が描画器、`scene.js` が絵を並べる。WebGL2 が使えない環境では、遊べない旨を出す。

## 視点と操作
- **一人称**。目の位置は 勇者の位置。**画面の中央が 照準**。マウスを動かした量だけ、見る向きが変わる。マウスの固定（ポインターロック）は、manifest の uses に `pointerLock` を書いて、ゲームを始めるときと「つづける」を押したときの クリックで `requestPointerLock()` を呼ぶ（まず加速なしの生の動きを頼み、だめならふつうに頼む）。Esc で外れ（ゲームは自動で中断し、「つづける」を押すと もう一度固定する）、タブが隠れたり ウィンドウから離れたときは、本体が外す。固定できない環境では、固定なしで遊ぶ（矢印キーで視点を回せる）。
- **三人称**も選べる（V、または 設定）。勇者の後ろの上から見る。
- **ロックオン補助**：照準が ボスから この角度の中なら、弾はボスの中心へ向く。設定で なし・5・7・10・14 度・**完全**。**はじめは 完全**（どこを向いていても 弾はボスへ向かう。弾をよけることと、砲を溜めて放すことに 集中できる。弱点は 当たった点の高さで決まるので、どこから撃つかは 自分で決める）。F を押している間は、視点がボスへ向く。
- **自動射撃**（設定：する・しない。はじめは する）：ふつうの弾を 押さなくても撃ちつづける。溜めている間と、反動の間は 止まり、放すと また撃つ。しないにすると、ショットのキーを押している間だけ撃つ。
- 手もとの砲身は 描かない（画面の右下から伸びる線は、見づらいだけなので 消した）。ふつうの弾は、照準のすぐ下から出る。
- **自動で向く**（設定：なし・弱・強。はじめは 弱）：視点を 動かしていないとき、ゆっくりボスのほうへ向く。
- 移動は **視点の向き**を基準にする（前へ = 見ている水平の向き）。上昇・下降は 別のキー。

| 操作 | はじめのキー・マウス | 
|---|---|
| 前・後・左・右 | W S A D |
| 上昇・下降 | Space・C |
| ダッシュ（短い無敵つき。0.9 秒に1回） | Shift |
| 精密移動（遅くなる。ショットが強くなる） | Z を押している間 |
| ショット（自動射撃を しないとき） | マウス左、J |
| 溜めて撃つ（押したまま溜めて、放すと発射。集束弾は もう一度押すと起爆） | マウス右、K |
| 弾の種類を選ぶ | 1〜8、E（次）Q（前）、ホイール |
| 同じ種類の、次のファイル | R |
| ボスのほうを向く | F（押している間）、マウス中ボタン |
| 一人称・三人称 | V |
| 視点を キーで回す（マウスを使わないとき） | 矢印キー |
| 中断 | Esc（変えられない）、P |

- **片手で全部**：左手が キーボード（W A S D・Space・C・Shift・Z・Q・E・R・F・V・1〜8）、右手が マウス（照準・ショット・溜め・ホイール）で、足りる。
- **キー設定**：武器庫と中断の画面に「操作設定」。操作ごとに 主・副の 2 つ割り当てられる。押して、新しいキーを押す。かぶったら 入れかえる。もとに戻すボタン。マウスの感度・視点の上下反転・自動射撃・補助の角度・自動で向く強さ・迫る弾の合図も ここで変える。保存される（`ep.storage` の `bind` `look`）。

## ファイル → 弾（`ammo.js`）
**種類**は拡張子で決まる。

| 種類 | 拡張子の例 | 撃ち方（溜めて放したあと） |
|---|---|---|
| 砲弾 | そのほか（コード・不明） | 貫通する狙撃。弾を消しながら進む。**遠いほど強い**（ボスまで 6 のとき 0.75 倍、30 で 1.65 倍） |
| 散弾 | png jpg gif svg webp … | 扇形のばらまき。上下にも広がる。**近いほど強い**（6 で 1.6 倍、20 で 0.7 倍。遠いと外れも多い） |
| 光線 | mp4 mkv mov avi webm … | 長く照らす。**撃っている間は動けないが、照準で向きを自由に変えられる**。通り道の弾を焼く。ボスからはずれている間は削れない |
| 音波 | mp3 wav flac m4a ogg … | 勇者を包む **球のバリア**。入った弾を消して、**弾き返してダメージにする**（1発 威力の 4.5%。合計は 威力の 1.5 倍まで）。バリアの間は動ける |
| 誘導弾 | pdf docx txt xlsx pptx … | 勇者に近づいてくる弾を先に **撃ち落とす**。撃ち落としても、その弾のぶんのダメージはボスに入る。撃ち落とす弾がなければ、ボスへ |
| 集束弾 | zip 7z rar tar gz … | ゆっくり飛ぶ爆弾。**もう一度 溜めるキーを押すと その場で起爆**（まわりの弾が消え、破片がボスを追う。破片だけで 威力の半分）。ボスにぶつかれば 全部入る |
| 爆裂弾 | exe msi bat apk jar … | 高く打ち上げて、**ボスの真上から落とす** 迫撃砲（ロックオン補助の外なら、照準の先へ）。落ちたところが大爆発で、中の弾を消す。弱点が『上』のとき強い |
| 隕石 | iso img vhd vmdk bin db … | 空から降らせる。降りきるまで時間がかかる。**いつも上から当たる**。高い所の弾も消す |

**大きさの段**：豆鉄砲（〜100KB）・小口径砲（〜5MB）・中口径砲（〜100MB）・大口径砲（〜1GB）・ロマン砲（1GB〜）・超ロマン砲（10GB〜）。段は表示の名前と、撃ったあとの反動・無敵・スローなど「演出」を決める。
威力・溜め・見た目の大きさ・**マス数**は、段ではなく**大きさの対数でなめらかにつなぐ**。

| 大きさ | 威力 | 溜め（秒） | 見た目の大きさ | マス数 |
|---|---|---|---|---|
| 1KB | 18 | 0.18 | 0.5 | 1 |
| 100KB | 40 | 0.32 | 0.7 | 2 |
| 5MB | 110 | 0.75 | 1.0 | 3 |
| 100MB | 300 | 1.4 | 1.6 | 5 |
| 1GB | 800 | 2.4 | 2.4 | 8 |
| 10GB | 2,200 | 3.8 | 3.6 | 12 |
| 100GB | 4,500 | 5.0 | 4.6 | 16 |

種類ごとの威力の倍率：光線 1.1・音波 0.7・誘導弾 1.15・爆裂弾 1.15・隕石 1.05・そのほか 1.0。同じファイルは、いつでも同じ砲・同じ形（名前・拡張子・大きさだけで決まる）。

**ロマンの代償**：溜めている間は遅く、大きいほど遅い（豆 85% → 超 30%）。撃ったあとは、段に応じて無敵（0.3 + 0.16 × 段 秒）、反動で動けない時間（大口径 0.15 秒、ロマン砲 0.45 秒、超 0.8 秒）、次の砲までの間（0.35 + 0.22 × 段 秒）。ロマン砲以上は、撃つ瞬間にスローになる。溜めの途中で被弾すると、溜めは消える。かすりで溜めが進む。

## マガジン（容量マップ。`puzzle.js`）
- 盤は 四角いマス目。はじめは 5×4 の 20 マス。整備場で 広げられる（5×4 → 6×4 → 6×5 → 7×5 → 7×6 → 8×6 → 8×7 → 9×7 → 9×8 → 10×8 の 10 段階）。
- ファイルは **ポリオミノ**（マスが つながった形）。マス数は 上の表（大きさの対数）。形は 名前から決まる（同じファイルは いつも同じ形）。ふくらんだ かたまりになるよう作る。
- はめかた：左のファイルを押して つまみ、盤の上で 置きたい所に カーソルを動かす（置ける所は 緑、置けない所は 赤）。**R か 右クリックで 90 度まわす**。クリックで置く。置いた形を押すと つまみなおせる（Esc で もとの場所へもどす）。つまんだ形は、盤に入る向きから はじまる。ファイルを ダブルクリックで、入る所へ 自動で置く。
- 「おまかせ詰め」：威力が マスあたりで大きいものから、入る所へ 順に置く。人が考えて詰めたほうが ふつうは多く持てる（役もねらえる）。「からにする」。
- 戦いの中では、**種類ごとの山**として扱う。1〜8 で種類を選ぶと、その種類の いちばん大きいファイルから使う。R で 同じ種類の次のファイルへ。使ったファイルは 盤から消える（ファイルそのものは消えない）。

## 役（`combos.js`）

## 強化素材と整備場（`meta.js`）
素材は 4 種類。面をクリアすると（やられたときは 倒したフェーズの割合だけ）手に入る。難しさで 量が変わる（やさしい 0.7・ふつう 1・むずかしい 1.3・ルナティック 1.7）。ノーミスなら +25%。
| 素材 | 1 面のクリアで | 使い道 |
|---|---|---|
| メモリ片 | 3 + 面の数 | マガジンを広げる |
| コア | 3 + 面の数 | 火力・溜め・ふつうの弾の強化 |
| プレート | 1 + 面の数 ÷ 2 | ライフ・速さの強化 |
| 設計図 | 1（偶数面は 2） | 役の解放 |

| 強化 | 段 | 1 段あたり | 費用（その素材の数。段ごと） |
|---|---|---|---|
| マガジン拡張 | 9 | 盤が広がる | メモリ片 3・4・5・6・8・10・12・14・16 |
| 火力 | 10 | 全砲・ふつうの弾の威力 +5% | コア 2・2・3・3・4・5・6・7・8・10 |
| 溜め | 5 | 溜め +5% | コア 3・4・5・6・8 |
| ふつうの弾 | 5 | ふつうの弾 +8% | コア 2・3・4・5・6 |
| 装甲 | 3 | ライフ +1 | プレート 3・5・8 |
| 機動 | 5 | 移動 +4% | プレート 2・3・4・5・6 |

強化は 役の効果と 足し算で、同じ上限がかかる。保存は `ep.storage` の `meta`。
**敵の強さ**：面が進むほど、体力 ×(1 + 0.25 × (面 − 1))、弾の数 +8%（2.0 倍まで）、弾の速さ +4.5%（1.5 倍まで）。さらに、ボスが 勇者から離れにくくなる（勇者との距離の上限が 24 から 1 面ごとに 1.6 ずつ縮み、13 まで）。強化した勇者が ちょうどついていける ように、傾きを決める（`play.mjs --human --progress` で確かめる。人ぐらいの腕のボットは 7〜14 面で やられる）。

## ボスと弾幕（`stages.js`・`patterns.js`）
- 弾幕には **高さの印**（`lay`）がある：`floor`（床。ほんとうの床のそば）・`low`・`mid`・`high`（ボスの高さを 基準に ±2.6）・`ceil`（天井のそば）・`player`（勇者の今の高さ）。場が広がったので、ボスの高さが 動いても 弾幕は ボスについて動く。
- 弾幕の型 13 種：`ring`（層を入れかえる・同時に出す。**傾けた輪** `tilt` もある）`spiral` `fan`（勇者の高さへ向ける）`flower` `rain`（勇者の頭の上から落ちる大玉。床に警告が出る）`drizzle` `lasers`（高さと厚みがある）`pillars`（床に警告が出て、高さに関係なく立つ）`bloom` `orbs` `burst`（全方向。床ではねかえる）`snake` `wall`（`tall` は 5 段の壁で、穴は 横と高さの両方。勇者の高さのまわりに 作る）。
- **ボスの動き**（フェーズごと）：`sway`（ゆれる）`orbit`（場の中心をまわる）`tilt`（かたむいた輪をえがいて 上がり下がり）`dart`（数秒おきに 勇者から離れた所へ 急に移る）`chase`（ゆっくり 近づいてくる）。高さも 変わる。
- 5 面まで手書き：断片化の蛇・キャッシュの亡霊・ダウンロードの巨人・レジストリの蜘蛛・ごみ箱の王（4 フェーズ）。6 面からは、面の番号と種から機械的に作る。
- 体力 = フェーズの基本 × 1.4 × (1 + 0.25 × (面 − 1)) × 難しさ。制限時間 = フェーズの基本 + 10 秒。難しさ：やさしい 0.8・ふつう 1・むずかしい 1.15・ルナティック 1.3。
- 難しさは、弾の数（`cm`）と速さ（`sm`）の倍率、最初のライフ（やさしい 5・ふつう 3・むずかしい 3・ルナティック 2）で変わる。

## 弱点
- 弱点のあるフェーズでは、ボスの **上・正面・下** のどれかが弱点になり、数秒おきに移る（移る 1.2 秒前に、次の向きが白く点滅し、画面の上に「弱点が移る」と出る）。1 面は 2 つ目のフェーズから。
- その向きから当たったダメージは **1.8 倍**（「超ロマン砲持ち」で さらに +40%）。向きは『当たった点が、ボスの中心から見て 水平より 7 度より上か下か』で決まる。勇者が ボスより高いところから撃てば 上から、低いところから撃てば 下から当たる。爆裂弾と隕石は、いつも上から当たる。
- 上や下になる高さは、ボスとの水平のへだたりで変わる。画面の **高度計** の金色が、その高さ。

## 画面（一人称の見やすさ）
- 中央の照準と、ロックオン補助が効いているときの 四角。
- **レーダー**（右下）：上から見た 勇者とボスと 近くの弾。上向きの弾・下向きの弾が わかる。
- **ボスの矢印**：ボスが 画面の外にいるとき、画面のふちに 向きを出す。
- **危険の合図**（`threat.js`）：勇者に 当たりそうな弾（このまま進むと 2 秒以内に、弾の半径 + 1.6 まで近づく）を探し、**画面に入っていない**ものを知らせる。
  - 画面のふちに、その向きを指す **三角のしるし**（20 方向に まとめる。近い時間ほど 大きく赤く）。
  - その向きが 真上・真下に近い（画面の上下 45 度以内）ときは、画面の上に「▲ 上から」、下に「▼ 下から」と 大きく出す。
  - 床の警告も 同じ扱い：勇者の近くに **雨の落ちる印**があるときは「▲ 真上から落ちてくる」、**柱の警告**があるときは「▼ 足もとから柱が立つ」。
  - 上・下の合図のときは、音も ちがう（上は 高い 2 音、下は 低い音）。
  - **レーダー**には、上から見た図のほかに、左に **高さの目盛り**（勇者から ±10m）。近くの弾が 上にあるか 下にあるかが わかる。雨の印・柱の警告も 円の中に出る。
  - 設定「迫る弾の合図」で 切れる（はじめは する）。
- 高度計（左）。弾の影と 床への線（近い弾だけ）。
- 画面の下に **種類ごとの山**（1〜8）：のこりの数、次に使うファイルの名前・大きさ・威力。溜めの進み。

## ふつうの弾
2 本×毎秒 11 回。ダメージ 1.4（精密移動で 1.9。役・強化で増える）。照準のほう（ロックオン補助が効けば ボスの中心）へ飛ぶ。1 面のフェーズは、ふつうの弾だけでも倒せる。

## 設定（manifest の settings）
効果音・音楽・音量・「画面のゆれと光の点滅をへらす」・画質・視野の広さ（はじめは 80 度）・練習モード。視点・キー・マウスの感度・補助・迫る弾の合図は、ゲームの中の「操作設定」。難しさと選んだ面は 武器庫の中。ベストスコア・到達した面・最大の一撃は `ep.storage` の `rec`、強化は `meta`、キーは `bind`、視点は `look` に残る。

## 確かめたこと・確かめられないこと
確かめる：ロジック全部（`unit.mjs` `parts.mjs` `game.mjs`）、ボットの通しプレイ（`play.mjs`。自由に飛ぶ）、ヘッドレスの Edge での画面と操作（`browser.mjs`。偽のポインターロックで、見る向き・ボタン・割り当て・中断・盤の操作・面のつながりまで）。
確かめられない：explorer_plus の本物の中での動き（偽の本体で代用）、手触り（一人称の照準・視点の回り方・キー配置）、音、本物の GPU での速さ。実機で動かないときは、まず `%APPDATA%\com.neoneptunity.explorerplus\logs\mod.neo.file-danmaku.log` を読む。
